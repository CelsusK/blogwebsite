My Colorful BlogOverview

My Colorful Blog is a website designed to share thoughts, ideas, and expertise on a variety of topics, with a focus on visual appeal and engaging content.

The site features a clean, responsive design with a light and dark theme option for enhanced user experience.

FeaturesResponsive Design: Adapts seamlessly to different screen sizes (desktops, tablets, and smartphones).

Light and Dark Themes: Users can switch between a light and dark color scheme.
Dynamic Navigation: Navigation menu highlights the active page.Engaging Content: Themed blog posts with images and structured content.
Technical DetailsHTMLindex.html: Homepage with featured and recent post sections.about.html: About page with information about the blog and author.
post.html: Displays individual blog posts.contact.html: Contact page with a form and contact information.CSSstyles.css: Provides modern and responsive styling for all HTML pages, including:Layout and structureColor palettes for light and dark themesTypographyResponsive design using media queriesJavaScriptscript.js:Implements theme switching functionality using localStorage.
Dynamically highlights the active navigation link.Content StructureThe core content of the blog is structured as follows:Featured Post: A highlighted article on the homepage.Recent Posts: A section on the homepage displaying the latest blog entries.Individual Posts: Detailed articles with titles, metadata, images, and formatted text.About Page: Information about the blog and the author.
Contact Page: A form and information for contacting the blog owner.How to UseNavigation: Use the navigation menu to visit different sections of the blog.Reading Posts: Click on post titles or "Read More" links to view full articles.
Theme Switching: Toggle between light and dark themes using the button in the navigation menu.
CustomizationContent:  To add new blog posts, create new HTML files (similar to post.html) and link them in the navigation.Styling:  Customize the appearance of the blog by modifying the CSS in styles.css.Functionality:  Extend the functionality of the blog by adding JavaScript code to script.js or creating additional JavaScript files.  For example, you could add features like search, comments, or social sharing.
