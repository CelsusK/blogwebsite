My Colorful BlogOverview

My Colorful Blog is a website designed to share thoughts, ideas, and expertise on a variety of topics, with a focus on visual appeal and engaging content.

The site features a clean, responsive design with a light and dark theme option for enhanced user experience.

FeaturesResponsive Design: Adapts seamlessly to different screen sizes (desktops, tablets, and smartphones).

Light and Dark Themes: Users can switch between a light and dark color scheme.

Dynamic Navigation: Navigation menu highlights the active page.Engaging Content: Themed blog posts with images and structured content.
Technologies Used are HTML,CSS and JavaScript
